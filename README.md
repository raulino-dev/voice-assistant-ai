# voice-assistant-ai
Desenvolvi um sistema que une Speech-to-Text e Text-to-Speech para conversas multi-idiomas por voz. Integrei o modelo Whisper com a API do OpenRouter para transcrever, traduzir e responder perguntas faladas com precisão. Como diferencial, implementei o Google Text-To-Speech (gTTS) para dar voz às respostas da IA. Com ajuda de Python e Java.
